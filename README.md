# CTF Square | Sealed Ledger
A standalone browser challenge with participant-bound flags, adapted from the CTF Square flag service and the synthetic Sealed Ledger exercise. Two participants encounter the same authorization flaw but recover different valid answers.

[Design and limitations](docs/design.md) · [Install and reset](docs/install.md) · [Reviewer walkthrough](docs/demo.md)

Run with Node.js 24: `node server.js`. Open http://127.0.0.1:8080 on the same machine. No package installation, database or cloud account required. This repository covers the local exercise only. No open-source license has been specified.
